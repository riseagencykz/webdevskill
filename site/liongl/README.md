# Lion Global Logistics — страница для хостинга

Самостоятельная страница, не блок Тильды. Кладётся в корень сайта как есть.

```
site/liongl/
├── index.html        собранная страница — её и заливать
├── assets/           логотип, OG-изображение
├── parts/            исходники, из них собирается index.html
│   ├── head.html     мета-теги, OG, favicon, шрифты
│   ├── style.css     стили
│   ├── body.html     разметка
│   └── app.js        скрипт
└── build.py          собирает index.html из parts/
```

**Править нужно `parts/`,** потом `python3 site/liongl/build.py`.
Одним файлом на 66 КБ пользоваться неудобно, поэтому разложено.

Посмотреть локально:

```bash
python3 -m http.server 8000 --directory site/liongl
```

## Чем отличается от версии для Тильды

`tilda/liongl/` остаётся на месте — это две сборки одной вёрстки.
Здесь снято всё, что было ограничением блока.

| | Тильда | Хостинг |
|---|---|---|
| Кнопки заявки | попап `#popup:myform` | **WhatsApp с готовым текстом** |
| Шрифты | в настройках сайта | подключены в `<head>` |
| `<head>`, OG, favicon | нет, их даёт Тильда | есть |
| Навигация по якорям | нет | есть, с подсветкой раздела |
| Точки на схеме | убраны | **вернул** |

### Кнопки теперь ведут в WhatsApp

Пять кнопок вели на `#popup:myform`. Без Тильды это мёртвые ссылки,
а попапа взять неоткуда. Все пять переведены на `wa.me/77715017775`
с подставленным текстом «Здравствуйте! Нужен просчёт маршрута».

**Это решение, а не единственный вариант.** Если нужна форма с полями,
её можно сделать: три строки из копирайта — откуда, куда, тонн — и есть
готовый бланк. Но форме нужен адресат: почтовый сервис, CRM или хотя бы
Formspree. Скажите, куда слать заявки, и я поставлю форму.

## Движение

Одна поставленная сцена, а не набор эффектов. Всё через `transform`
и `opacity`, кроме отрисовки линий схемы.

**Первый экран** — элементы поднимаются лесенкой по 70 мс, один раз
при загрузке.

**Схема коридоров** — сцена на 2 секунды, запускается один раз, когда
схема попадает в кадр:

1. прочерчивается рамка зоны ЕАЭС;
2. по очереди рисуются коридоры, Китай — пунктиром;
3. узлы выскакивают с лёгким перелётом, по 70 мс друг за другом;
4. проявляются подписи, граница и таможня;
5. и только потом запускаются точки, идущие по маршрутам.

**Точки не крутятся вхолостую.** Они останавливаются, когда схема
уходит с экрана или вкладка становится фоновой — через
`svg.pauseAnimations()` и `visibilitychange`. В прототипе они шли
бесконечно и жгли батарею на телефоне.

**Пять шагов** — вертикальная линия заполняется по мере прокрутки
секции, точки шагов загораются по ходу.

**Мелочи:** силуэт машины подаётся вперёд на 6 px при наведении вместе
с подсветкой габаритов кузова; карточки преимуществ меняют фон;
шапка уплотняется после 40 px прокрутки и подсвечивает текущий раздел.

`prefers-reduced-motion` выключает всё: сцена схемы показывается сразу
готовой, точки скрываются совсем, линия шагов стоит заполненной.

## Проверено в браузере

Chromium, ширины 320 / 390 / 480 / 768 / 1024 / 1440:

- горизонтального скролла нет ни на одной;
- ошибок в консоли нет;
- **мёртвых ссылок нет** — все пять попапов заменены;
- 21 фокусируемый элемент, порядок совпадает с визуальным,
  фокус виден на светлом и на тёмном;
- все текстовые пары проходят WCAG AA;
- сцена схемы отыгрывает и не повторяется при возврате на вкладку;
- линия прогресса доходит до конца;
- при `prefers-reduced-motion` и без JS ничего не остаётся скрытым;
- цели нажатия не ниже 44 px, кроме одной — см. ниже.

### Осознанное исключение

Телефон в мелком тексте лид-магнита ниже 44 px. Это инлайновая ссылка
внутри предложения «Или сразу позвоните: …». Увеличивать её — ломать
межстрочный интервал. Правило 44 px относится к самостоятельным
элементам управления, все они в норме.

## Шрифты и CLS

Inter и IBM Plex Mono подключены в `<head>` с `preconnect`
и `display=swap`.

**Замер показал риск:** когда Inter приезжает после первой отрисовки,
заголовок первого экрана меняет число строк и тянет за собой всё ниже —
CLS **0.165** на медленном 4G. Сам блок без шрифтов даёт LCP 332 мс
и CLS 0.

Два способа закрыть это, оба в одну строку в `parts/head.html`:

1. **Предзагрузка.** Добавить `<link rel="preload" as="style">` к ссылке
   на шрифты. Шрифт приезжает раньше первой отрисовки, CLS падает в ноль.
2. **`display=optional` вместо `display=swap`.** Тогда браузер вообще
   не подменяет шрифт на лету: кто не успел загрузить за ~100 мс, видит
   системный до следующего захода. CLS гарантированно ноль, ценой того,
   что часть первых посетителей не увидит Inter.

Я оставил `swap` как поведение по умолчанию: это компромисс, а выбор
между «всегда фирменный шрифт» и «никогда не дёргается вёрстка» —
ваш, а не мой.

Оговорка по цифре: Inter и Google Fonts из моего окружения недоступны,
подменялись два системных гротеска с большой разницей метрик.
**0.165 — худший случай, а не ожидаемый.**

«Партнёры, которые нам доверяют» из вашей презентации.

письменного согласия. Если по кому-то сомневаетесь — уберите строку
из разметки, это один блок `<ul class="lgl-clients">`.

Презентация продаёт всё: авиа, море, ЖД, мультимодальные, спецтехнику,
направления от Евросоюза до Америки и ОАЭ. **На лендинг я это не

Если нужен раздел про остальные услуги — он должен быть отдельной
страницей или блоком ниже контактов, а не в первом экране.
