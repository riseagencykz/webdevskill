# Voltek Казахстан — макет сайта

Статический сайт, готов к заливке на любой хостинг: содержимое папки `site/`
кладётся в корень домена (`index.html` + `assets/`). Ни PHP, ни базы не нужно.

```
voltek-kz/
├── site/                 ← это и есть сайт, его заливать
│   ├── index.html        (собран, не править руками)
│   └── assets/  style.css · app.js · img/
├── src/index.src.html    ← шаблон страницы, тексты правятся здесь
├── data/models.json      ← характеристики 17 моделей (с voltek-electro.ru, 16.11.2026)
├── build.py              ← собирает site/index.html из шаблона и данных
└── RESEARCH.md           ← разбор сайта РФ
```

После правки шаблона или данных: `python3 build.py`.

## Что заполнить перед запуском

| Где | Что |
|---|---|
| `site/assets/app.js`, `CFG.whatsapp` | номер WhatsApp, только цифры (сейчас `77000000000`) |
| `src/index.src.html`, блок `#zayavka` | телефон, почта, адрес склада (помечены `data-todo`) |
| `src/index.src.html`, подвал | ТОО, БИН |
| `site/assets/products/` | фото моделей. Имена — как в `data/models.json` → `photo` (например `voltek-is-1000_01.jpg`). Пока папки нет, фото грузятся с voltek-electro.ru, а если не загрузились — показывается рисунок-заглушка |
| ссылки на PDF в блоке `#dokumenty` | сейчас ведут на сайт РФ; лучше положить файлы в `site/docs/` |

## Как работает

- **Осциллограф в первом экране** — SVG, рисуется в `requestAnimationFrame`,
  останавливается, когда блок не виден или вкладка свёрнута; при
  «уменьшить движение» в системе — статичный кадр.
- **Подбор мощности** — нагрузка × 1,2 должна уместиться в нижнюю границу
  модели по кВт, а пуск самого тяжёлого мотора — в кратковременную
  перегрузку серии (IS 150 %, ТСН 200 %). Мощности приборов типовые,
  список — `APPLIANCES` в `build.py`.
- **Заявка** открывает WhatsApp с готовым текстом. Если нужно на почту или
  в amoCRM — можно взять `send.php` от сайта Lion Global Logistics.
- **«Узнать цену»** у карточки или в подборе подставляет модель в поле заявки.
