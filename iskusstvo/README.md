# Школа тату «Искусство» — посадочная под курс «Стань тату-мастером»

Один файл `index.html` плюс папка `assets/img/`. Никаких сборок и зависимостей:
кладётся на любой хостинг, открывается двойным кликом, правится в блокноте.

```
iskusstvo/
├── index.html          вся страница: разметка, стили и скрипт внутри
└── assets/
    ├── img/            фотографии мастеров и работ учеников (14 файлов)
    └── art/            гравюры, вырезанные с ваших титульных слайдов
```

Посмотреть локально:

```bash
python3 -m http.server 8000 --directory iskusstvo
# → http://localhost:8000
```

## Блок «Точка А → Б» — почему он стоит вторым

Это самый сильный аргумент в ваших материалах, и он единственный,
который нельзя подделать: **Ася и Аружан, которые сегодня работают
старшими мастерами и обучают, сами пришли на этот курс с нуля.**
Элеонора — свежий пример, выпуск 2025 года.

Обычные отзывы «мне понравилось» такого не дают. Поэтому блок идёт сразу
после первого экрана, до программы и до пакетов.

**Одна нестыковка, которую надо проверить.** В презентации Аружан
показана на двух слайдах с разными фотографиями. Я взял ту, что со слайда
мастеров. Если это разные люди или фото перепутано — скажите,
поменяю (`assets/img/master_aruzhan.jpg` и `ab_eleonora.jpg`).

## Кнопки ведут в WhatsApp

Формы на странице нет. Все шесть кнопок открывают чат с номером
`77773231144` и подставленным сообщением. Меняется двумя строками
в скрипте внизу файла:

```js
var WA_PHONE = '77773231144';
var WA_TEXT  = 'Здравствуйте! Хочу узнать про курс тату-мастера';
```

Полный адрес продублирован в самой разметке — если скрипт по какой-то
причине не отработает, кнопка всё равно откроет чат с готовым текстом.

### Атрибуция

Заявка не проходит через форму, поэтому UTM-метки сами никуда не попадут.
Чтобы срез по роликам не потерялся, в текст сообщения дописывается
короткая метка креатива:

> Здравствуйте! Хочу узнать про курс тату-мастера **#tt_creative_7**

Берётся из `utm_content`, иначе `utm_campaign`, иначе `utm_source`.
Без меток в ссылке сообщение остаётся чистым. Выключается строкой
`var WA_TAG_SOURCE = false;`

### Событие конверсии

Страницы «Спасибо» нет, поэтому пиксель срабатывает на клике по кнопке:
страница вызывает `ttq.track('Contact')` и `fbq('track','Contact')`,
если пиксели подключены. **Без этого TikTok не увидит ни одной конверсии
и оптимизировать кампанию будет не по чему.** Вызовы обёрнуты в try —
если пиксель не подключён, ошибки не будет.

Первая версия была чёрная, с толстыми рамками и жёсткими тенями — это
был мой стиль, а не ваш. Сейчас страница построена на элементах,
которые уже есть в вашей презентации.

| Элемент | Откуда |
|---|---|
| Белый лист как основа | все слайды |
| Жёлтый `#FFD453` | пипеткой с полос на титульном слайде |
| Тёплый чёрный `#231F1F` | пипеткой с заголовков (не чистый чёрный) |
| Жёлтые плиты по краям | вертикальная слева + горизонтальная справа снизу — на каждом слайде |
| Выноски с обводкой 2 px и скруглением | слайд «Выбор краски» |

| Античные гравюры | титульный слайд, «Программа обучения», «Содержание» |

### Гравюры

Три вырезаны прямо с ваших слайдов и лежат в `assets/art/`:

- `bust_main.png` — женский профиль с титульного слайда, стоит в первом экране;
- `column.png` — ионическая капитель со слайда «Программа обучения», рядом с программой;
- `figure.png` — драпированная фигура со слайда «Содержание», рядом с вопросами.

Фон у них прозрачный, линия чёрная. Если хотите другие — пришлите
исходники в PNG или SVG, файлы просто заменяются по этим именам.

С мобильной версии капитель и фигура убраны: на 390 px они бы отняли
экран у текста и кнопки. Бюст в первом экране остаётся везде.

### Главное правило палитры

**У вас жёлтое — это графика, а не подложка под текст.** На слайдах
плиты стоят пустыми, текст на них не лежит ни разу. На странице
это правило соблюдается везде, кроме одного места — финального экрана,
где текст лежит на жёлтом сознательно, ради последнего акцента.
Там тёплый чёрный на жёлтом даёт 11.49, это заведомо читаемо.

**Белый текст на жёлтом даёт 1.59 и нечитаем.** Если будете добавлять
блоки — на жёлтом только тёплый чёрный. Это записано комментарием
в начале стилей.

Все сочетания проверены и проходят WCAG AA (минимум 4.5):

| Сочетание | Контраст |
|---|---|
| белый фон / тёплый чёрный `#231F1F` | 16.31 |
| жёлтый фон / тёплый чёрный | 11.49 |
| чёрная кнопка / белый текст | 16.31 |
| белый фон / текст лида `#5A5553` | 7.35 |
| белый фон / основной текст `#6B6663` | 5.67 |
| серый фон `#F7F7F7` / основной текст | 5.29 |
