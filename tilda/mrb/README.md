# Mr B Academy — лендинг для Тильды

**Один файл: `mr-b-academy.html`.** Скопировать целиком → вставить в блок
**T123 «HTML-код»** → сохранить. Всё остальное уже внутри: попап с квизом,
маска телефона, сбор UTM, sticky-кнопка, анимации.

Отдельный попап-блок в Тильде создавать **не нужно** — он встроен в этот же файл.

---

## Что сделать после вставки

### 1. Убрать шапку и футер
Настройки страницы → отключить меню. На первом экране не должно быть
ничего, кроме заголовка и одной кнопки — трафик холодный, из TikTok.

### 2. Подключить AmoCRM
**Настройки сайта → Формы → AmoCRM.** Форма отдаёт эти поля:

| Поле | Имя |
|---|---|
| Имя | `Name` |
| Телефон | `Phone` |
| Цель | `Цель` |
| Срок | `Срок` |
| Уровень | `Уровень` |
| Метки источника | `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term` |
| TikTok click id | `ttclid` |
| Адрес страницы | `page_url` |

`Цель / Срок / Уровень` — те самые четыре критерия квалификации, что уже
заведены в CRM. Менеджер видит квал до первого звонка.

### 3. Страница «Спасибо»
Создать отдельную страницу и указать её в настройках формы
(*После отправки → Перенаправить на страницу*). События пикселей вешать **на неё** —
так событие не теряется и не задваивается.

### 4. Шрифт (по желанию)
Файл подключает Manrope сам. Для чуть более быстрой загрузки перенесите
подключение в *Настройки сайта → Шрифты* и удалите три строки `<link>`
в начале файла.

---

## ⚠️ Форма отправляется только на опубликованной странице

В редакторе и превью Тильды объекта `tildaForm` не существует, поэтому отправка
там физически не работает. Вместо тишины блок покажет прямое предупреждение:

> Отправка работает только на опубликованной странице — здесь tildaForm недоступен.

Это ожидаемое поведение, а не поломка. **Проверять форму нужно на опубликованной
странице.** Ложного «Заявка принята» блок не показывает никогда — иначе можно
решить, что лиды идут, когда их нет.

## Мультилендинг под разные креативы

Заголовок первого экрана меняется прямо в ссылке объявления, без копий страницы:

```
/?h=Сдать IELTS 7.0 с нуля за год
/?h=IELTS за 10 недель&sub=Преподаватель с опытом экзаменатора Cambridge
```

Без параметров остаётся текст из файла. Подстановка безопасная — HTML из
параметра не исполняется (проверено инъекцией `<img src=x onerror=...>`).

Первый экран должен продолжать мысль ролика, а не начинаться заново —
под каждую связку свой `?h=`.

## Что заменить перед запуском

| Что | Где искать в файле |
|---|---|
| **Фото преподавателя** | `mrb-expert-photo`, сейчас SVG-силуэт. Формат 4:5 |
| Скриншоты баллов | `mrb-shot` ×2 |
| Отзывы и баллы | `mrb-quote-text`, `Band 7.5` |
| Стаж «15+» | `data-mrb-count="15"` |
| Цены | `75 000 ₸`, `250 000 ₸` |
| Адрес | «Астана · левый берег» |

Секция «Результаты» **скрывается сама**, пока в ней нет ни одного блока
`mrb-result` — можно публиковаться без неё и наполнить позже.
Удалите четыре `<li class="mrb-result ...">`, и секции не будет.

Фото преподавателя лучше сделать настоящее: на нём держится весь оффер
и главное отличие от конкурентов без личного бренда. Стоки для него не подойдут.

## Аналитика

Ставится в настройки сайта и на страницу «Спасибо», не в этот блок.

- **TikTok Pixel + Events API** — событие `SubmitForm` на странице «Спасибо».
  `ttclid` уже собирается блоком и уходит в CRM, его нужно передавать
  в Events API для матчинга.
- **Meta Pixel** — ставить параллельно, чтобы при перераспределении бюджета
  не остаться без накопленных данных.
- **UTM** размечать на уровне объявления — тогда в AmoCRM виден срез
  по конкретному ролику.
- **Цель оптимизации — «квал», а не «заявка».** Иначе кампания уедет
  в объём дешёвых нецелевых лидов.

## Проверено в браузере

Chromium, ширины 360 / 390 / 480 / 640 / 768 / 1024 / 1440:

- первый экран умещается в 390×844 без скролла — 804 px;
- горизонтального скролла нет ни на одной ширине, ошибок в консоли нет;
- попап: открытие, блокировка фона, `Esc`, шаги, прогресс, «Назад»;
- маска телефона: `7019998877`, `87019998877`, вставка `+7 701 999 88 77`
  → `+7 (701) 999-88-77`;
- UTM и `ttclid` попадают в скрытые поля и переживают переход внутри сайта;
- при наличии `tildaForm` управление уходит Тильде, при отсутствии —
  предупреждение и никакой перезагрузки страницы;
- sticky-кнопка появляется после 40 % скролла и прячется на финальном экране;
- контент не теряется даже при мгновенном прыжке в конец страницы.

**Не проверено:** фактическая доставка лида в AmoCRM и срабатывание пикселей —
для этого нужна опубликованная страница с живым `tildaForm`.

### Известное ограничение

Ввод `77019998877` даёт `+7 (770) 199-98-87`. Это осознанно: `770` — реальный код
Tele2/Altel, и срезать ведущую семёрку как «код страны» нельзя, иначе сломаются
все номера на 770. Восьмёрка в начале срезается корректно.
