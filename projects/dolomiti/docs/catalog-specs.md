## Как читались данные

`pdftotext` извлекает из каталога только подписи полей («МОЩНОСТЬ:», «ВЕС:», «РАЗМЕР:»), но **не сами числа** — числовые значения набраны шрифтом, который не извлекается (`Syntax Error: Unknown font tag 'C0_0'`, отсутствует маппинг `Adobe-GB1`). Поэтому все цифры ниже прочитаны визуально с растров страниц (`pdftoppm -r 150…1000 -png`). Ничего не достраивалось по аналогии: если параметра в каталоге нет — в ячейке стоит «нет в каталоге».

**Про Crown и Pillar-E.** Каталог в одной строке даёт два артикула: `CR60B/CR60BE`. Из текста раздела Crown: «Модель имеет встроенное или внешнее управление» — то есть **B** = исполнение со встроенным блоком управления, **BE** = исполнение под внешний пульт. Аналогично `PH60E PH60BE`, `SD90E SD90BE`, `TH105E TH105BE`. Характеристики (габариты, масса, камни) в каталоге даны **общие на строку**, раздельно для B и BE они не приводятся.

**Про CL32WF-C / CL50WF-C.** В каталоге нет пультов с такими названиями. Есть пульт **Classy** в двух вариантах панели — «Classy (WIFI)» (PDF стр. 3) и «Classy» без Wi-Fi и без дверного выключателя (PDF стр. 4). К обоим вариантам предлагается на выбор один из трёх силовых блоков: `CL32WF-C`, `CL50WF-C`, `CL40WF-R`. На стр. 3 они подписаны с суффиксом WIFI (`CL32WF-C WIFI`), на стр. 4 — без него, характеристики в обоих случаях одинаковые. То есть CL32WF-C и CL50WF-C различаются **только предельной мощностью**, а не наличием Wi-Fi. На страницах печей этот пульт обозначается как «CL32/40WF(WIFI)».
