## 2. Где я отступил от скилла и почему

Отступления осознанные — бриф и техрегламент приоритетнее выдачи базы.

### 2.1. Генератор дизайн-системы отклонён целиком

```bash
python3 src/ui-ux-pro-max/scripts/search.py "IELTS English school landing mobile TikTok lead generation Astana" \
  --design-system --variance 4 --motion 4 --density 4
```

Выдал: палитру **«AI purple + generation pink»** (`#7C3AED` / `#EC4899`), пару
**EB Garamond / Crimson Text** с пометкой *«academic, old-school, university»* и
GSAP-сниппет для анимаций.

Не взято, три прямых конфликта с брифом:

- фиолетово-розовая «AI»-палитра не имеет отношения к подготовке к IELTS — авто-детект
  зацепился за формулировку запроса, а не за нишу;
- академический сериф прямо противоречит требованию «без академической сухости»,
  и это две семьи вместо одной;
- GSAP — внешняя библиотека, запрещена бюджетом производительности.

Вместо этого взяты точечные доменные запросы из таблицы выше — они дали релевантный
результат. Генератор полезен на старте проекта, но здесь бриф детальнее его входных дилов.

### 2.2. Стиль: не Claymorphism

`products.csv` рекомендует для Educational App **Claymorphism + Micro-interactions**,
«playful colors». Отвергнуто: бриф требует «уверенный экспертный, без инфоцыганского
пафоса», аудитория — взрослые и родители. Игровая пластика убила бы доверие,
на котором держится оффер. Взята строгая типографическая подача:
крупный кегль, высокий контраст, воздух.

### 2.3. Акцент затемнён: `#EA580C` → `#C2410C`

`colors.csv` отдаёт `#EA580C` (уже подправленный от `#F97316` «for WCAG 3:1»).
Но 3:1 — порог для **не-текстовых** элементов, а у нас это фон кнопки с белым
текстом, где нужно 4.5:1.

| | ratio | |
|---|---|---|
| белый на `#EA580C` | 3.56 | ✗ ниже AA |
| белый на `#C2410C` | **5.18** | ✓ AA при любом кегле |

Главная кнопка — единственный элемент, ради которого существует страница;
полагаться на исключение для крупного текста здесь неоправданно.

### 2.4. Один шрифт вместо пары

`typography.csv` оперирует парами и тройками семей. Бриф жёстко ограничивает:
«шрифт один, два начертания». Поэтому выбор шёл по `google-fonts.csv`,
критерии — наличие `cyrillic` в subsets (сайт русскоязычный) и нужные начертания.
**Manrope 400/800**: кириллица есть, автор Михаил Шаранда, ранг популярности 38.

### 2.5. Бордюр не `#5EEAD4`

Значение `Border: #5EEAD4` из палитры — насыщенный бирюзовый, для волосяных линий
на белом слишком яркий, спорит с единственным акцентом на CTA.
Оставлен для акцентных рамок (`--mrb-border-teal`), для обычных — нейтральный `#E2E8F0`.

### 2.6. FAQ — совпадений в базе нет

```
--domain ux "accordion FAQ disclosure"  ->  Found: 0 results
```

Скилл честно вернул пустой результат. Явно фиксирую: аккордеон сделан **не по базе**,
а по требованию брифа — нативный `<details>/<summary>`, без JS и без ARIA-костылей.

## 3. Итоговые токены

### Цвет

| Роль | Значение | Контраст |
|---|---|---|
| Заголовки `--mrb-ink` | `#134E4A` | 9.48:1 на белом ✓ AA |
| Текст `--mrb-body` | `#334155` | 10.9:1 ✓ AA |
| Второстепенный `--mrb-muted-fg` | `#64748B` | 4.76:1 ✓ AA |
| Бренд `--mrb-teal` | `#0D9488` | 3.74:1 — только не-текст ✓ |
| **CTA `--mrb-cta`** | `#C2410C` | белый текст 5.18:1 ✓ AA |
| Подложка `--mrb-surface` | `#F0FDFA` | ink на ней 9.09:1 ✓ AA |

Акцент `--mrb-cta` встречается **только** на кнопках целевого действия.
Ни заголовки, ни иконки, ни рамки его не используют — иначе кнопка перестаёт
выделяться, а это единственное, что должно притягивать взгляд.

### Типографика

Manrope, 400 и 800. Шкала на `clamp()` от 390px до 1440px — промежуточных
брейкпоинтов для кегля не требуется.

`H1 → body` = 3.5rem / 1rem = **3.5:1** на десктопе.

### Ритм

Шаг 4px. Вертикальные отступы секций — `clamp(48px, 9vw, 96px)`.
Density 4/10 из брифа — «много воздуха», поэтому шкала ближе к разреженной.

### Движение

Scroll Reveal (Subtle) из `motion.csv`: 340 мс, сдвиг 14px, `cubic-bezier(.22,.61,.36,1)`.
Реализация — `IntersectionObserver` + CSS-переход, без библиотек.

Обязательное условие из той же строки базы:

> *Don't reveal below-the-fold content needed for SEO/crawlers as invisible-by-default
> without a no-JS fallback*

Поэтому у `.mrb-reveal` начальное состояние задаётся **из JS** (класс `mrb-js` на корне).
Без JS и для краулеров весь контент видим сразу.
