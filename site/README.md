# Mr B Academy — новый сайт

Многостраничный сайт на замену liongl.kz. Обычный статический HTML: открывается
двойным кликом, кладётся на любой хостинг, правится в любом редакторе.

```
site/
├── index.html      Главная
├── programs.html   Программы
├── about.html      О школе и менторе
├── contacts.html   Контакты
├── privacy.html    Политика конфиденциальности
└── assets/
    ├── styles.css  Все стили
    └── app.js      Меню, ссылки в WhatsApp, метки источника
```

Посмотреть локально:

```bash
python3 -m http.server 8000 --directory site
# → http://localhost:8000
```

## ⚠️ Старый сайт я не видел

`liongl.kz` из моего окружения недоступен — сетевая политика отклоняет соединение:

```
"detail": "gateway answered 403 to CONNECT (policy denial or upstream failure)",
"host": "liongl.kz:443"
```

Поэтому **это не переработка старого сайта, а новый сайт, собранный
на фактах, которые вы подтвердили в этой переписке**: ниша, гео, Бекжан
и его регалии, модель «ментор + преподаватели», два трека,
бесплатный пробный урок, реквизиты ИП.

Что почти наверняка есть на старом сайте, но чего у меня нет:

- реальные телефон, почта, адрес, соцсети;
- отзывы и результаты учеников;
- фотографии школы и занятий;
- состав команды преподавателей;
- другие услуги, если они есть (детские группы, другие экзамены, разговорные клубы).

Пришлите — добавлю. Пока в файлах стоят пометки `ЗАПОЛНИТЬ`.

## Кнопки ведут в WhatsApp

Формы на сайте нет. Все кнопки открывают чат с номером `77025648350`
и подставленным сообщением. Меняется двумя строками в `assets/app.js`:

```js
var WA_PHONE = '77025648350';
var WA_TEXT  = 'Добрый день! Хочу записаться на пробный урок';
```

### Атрибуция

Заявка не проходит через форму, поэтому UTM-метки в CRM сами не попадут.
Чтобы срез по роликам не потерялся, в текст сообщения дописывается короткая
метка креатива:

> Добрый день! Хочу записаться на пробный урок **#creative_b**

Берётся из `utm_content`, иначе `utm_campaign`, иначе `utm_source`.
Без меток в ссылке сообщение остаётся чистым. Выключается строкой
`var WA_TAG_SOURCE = false;`

### Событие конверсии

Страницы «Спасибо» нет, поэтому пиксель срабатывает на клике по кнопке:
сайт вызывает `ttq.track('Contact')` и `fbq('track','Contact')`, если пиксели
подключены. Без этого TikTok не увидит конверсий и оптимизировать будет не по чему.

## Персональные данные

По Закону РК «О персональных данных и их защите» № 94-V от 21 мая 2013 года:

- **галочки согласия нет** — вместе с формой: человек пишет в WhatsApp сам,
  и это добровольная передача данных. Текст политики под это поправлен,
  но покажите юристу — для такого сценария он может захотеть другую формулировку;
- ссылка на политику в футере каждой страницы;
- реквизиты ИП в футере каждой страницы;
- отдельная страница политики.

**`privacy.html` — рабочий шаблон, юридически не выверенный.** Перед публикацией
покажите юристу и заполните помеченные места. Проверьте раздел 4: там перечислены
хостинг, CRM и аналитика — если появятся другие сервисы, их нужно указать.

## Дизайн

Палитра и шрифт унаследованы от лендинга — бренд должен читаться одинаково
на всех носителях, а контраст там уже выверен. Обоснование значений —
`design-system/mrb/README.md`.

Единственный акцентный цвет `#C2410C` используется **только** на кнопках
целевого действия. Если раскрасить им что-то ещё, кнопка перестанет
выделяться.

Многостраничного паттерна в базе скилла нет — на запрос
`--domain landing "multi page website navigation structure education school"`
она отдала лендинговые схемы (Event/Conference, Horizontal Scroll), которые
сюда не подходят. Структура сделана по обычным конвенциям сайта, а из базы
взяты точечные правила: активный пункт меню, skip-link, WebP для изображений.

## Проверено в браузере

Chromium, ширины 390 и 1440, все пять страниц:

- горизонтального скролла нет нигде, ошибок в консоли нет;
- активный пункт меню подсвечивается на каждой странице;
- все внутренние ссылки ведут на существующие файлы;
- все кнопки ведут на номер `77025648350`, метка креатива попадает в текст
  сообщения, а без меток в ссылке сообщение остаётся чистым;
- событие пикселя срабатывает на клике по кнопке;
- контент проявляется даже при мгновенном прыжке в конец страницы;
- если картинки с CDN не загрузятся, вместо битых иконок будут запасные
  элементы (надпись вместо логотипа, силуэт вместо фото).

**Не проверено:** вид с реальными логотипом и фото — CDN Тильды из моего
окружения тоже недоступен (403), в тестах стояли заглушки. Проверьте
кадрирование фото и видимость логотипа на светлом фоне после публикации.

### Осознанные исключения

Ссылка «о школе» внутри ответа в FAQ меньше 44 px. Это инлайновые ссылки
в тексте — увеличивать их значит ломать межстрочный интервал.
Правило 44 px относится к самостоятельным элементам управления,
все они в норме.
