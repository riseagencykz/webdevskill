# Школа тату «Искусство» — посадочная под курс «Стань тату-мастером»

Один файл `index.html` плюс папка `assets/img/`. Никаких сборок и зависимостей:
кладётся на любой хостинг, открывается двойным кликом, правится в блокноте.

```
iskusstvo/
├── index.html          вся страница: разметка, стили и скрипт внутри
└── assets/img/         фотографии мастеров и работ учеников (14 файлов)
```

Посмотреть локально:

```bash
python3 -m http.server 8000 --directory iskusstvo
# → http://localhost:8000
```

## Блок «Точка А → Б» — почему он стоит вторым

Это самый сильный аргумент в ваших материалах, и он единственный,
который нельзя подделать: **Ася и Аружан, которые сегодня работают
старшими мастерами и обучают, сами пришли на этот курс с нуля.**
Элеонора — свежий пример, выпуск 2025 года.

Обычные отзывы «мне понравилось» такого не дают. Поэтому блок идёт сразу
после первого экрана, до программы и до пакетов.

**Одна нестыковка, которую надо проверить.** В презентации Аружан
показана на двух слайдах с разными фотографиями. Я взял ту, что со слайда
мастеров. Если это разные люди или фото перепутано — скажите,
поменяю (`assets/img/master_aruzhan.jpg` и `ab_eleonora.jpg`).

## Кнопки ведут в WhatsApp

Формы на странице нет. Все шесть кнопок открывают чат с номером
`77773231144` и подставленным сообщением. Меняется двумя строками
в скрипте внизу файла:

```js
var WA_PHONE = '77773231144';
var WA_TEXT  = 'Здравствуйте! Хочу узнать про курс тату-мастера';
```

Полный адрес продублирован в самой разметке — если скрипт по какой-то
причине не отработает, кнопка всё равно откроет чат с готовым текстом.

### Атрибуция

Заявка не проходит через форму, поэтому UTM-метки сами никуда не попадут.
Чтобы срез по роликам не потерялся, в текст сообщения дописывается
короткая метка креатива:

> Здравствуйте! Хочу узнать про курс тату-мастера **#tt_creative_7**

Берётся из `utm_content`, иначе `utm_campaign`, иначе `utm_source`.
Без меток в ссылке сообщение остаётся чистым. Выключается строкой
`var WA_TAG_SOURCE = false;`

### Событие конверсии

Страницы «Спасибо» нет, поэтому пиксель срабатывает на клике по кнопке:
страница вызывает `ttq.track('Contact')` и `fbq('track','Contact')`,
если пиксели подключены. **Без этого TikTok не увидит ни одной конверсии
и оптимизировать кампанию будет не по чему.** Вызовы обёрнуты в try —
если пиксель не подключён, ошибки не будет.

## Что заполнить перед запуском

| Где | Что |
|---|---|
| Подвал, строка `<!-- ЗАПОЛНИТЬ ... -->` | реквизиты ИП/ТОО и ссылка на политику конфиденциальности |

Про политику: формы на странице нет, но пиксели TikTok и Meta ставят
куки, поэтому политика всё равно нужна — по Закону РК «О персональных
данных и их защите» № 94-V от 21 мая 2013 года. Готового текста
я сюда не клал, чтобы не выдавать шаблон за юридический документ.
Если нужно — сделаю заготовку по образцу той, что писал для Mr B Academy
(`tilda/mrb/privacy.html`), но её всё равно должен посмотреть юрист.

## Дизайн

Палитра и подача взяты с ваших слайдов: жёлтый `#F5C842`, чёрный,
белый. Заголовки — Oswald (узкий гротеск в верхнем регистре, как
в презентации), текст — Manrope. Оба из Google Fonts, подключены одной
строкой в `<head>`.

Рамки в 2 px и жёсткая тень без размытия (`5px 5px 0`) — это
брутализм из базы навыка ui-ux-pro-max. Он подходит тату-студии:
графично, дёшево в поддержке и не спорит с фотографиями работ,
которые на странице главные.

### Одно правило, которое нельзя нарушать

**Белый текст на фирменном жёлтом даёт контраст 1.59 — он нечитаем.**
На жёлтом фоне только чёрный (12.47). Это записано комментарием
в начале стилей. Если будете добавлять блоки — держите это в голове.

Все остальные сочетания проверены и проходят WCAG AA:

| Сочетание | Контраст |
|---|---|
| чёрный фон / белый | 19.80 |
| чёрный фон / жёлтый | 12.47 |
| жёлтый фон / чёрный | 12.47 |
| белый / основной текст `#3A3A3A` | 11.37 |
| светло-серый фон / серый текст | 4.97 |
| чёрный фон / мелкий текст подвала | 4.61 |

Минимум для обычного текста — 4.5.

## Проверено в браузере

Chromium, ширины 320 / 360 / 390 / 780 / 781 / 1079 / 1080 / 1440:

- горизонтального скролла нет ни на одной ширине;
- ошибок в консоли нет;
- все 13 фотографий загружаются;
- все 6 кнопок ведут на номер `77773231144`, метка креатива попадает
  в текст сообщения, без меток сообщение остаётся чистым;
- событие пикселя срабатывает на клике, в том числе по иконке внутри кнопки
  (проверено на подставных `ttq` и `fbq`);
- все нажимаемые элементы не ниже 44 px;
- контент проявляется даже при мгновенном прыжке в конец страницы;
- при отключённом JS и при `prefers-reduced-motion` ничего не остаётся
  скрытым, кнопки работают;
- FAQ раскрывается, липкая кнопка появляется после 35 % прокрутки
  и прячется на финальном экране, чтобы не перекрывать основную кнопку.

**Что я проверить не мог:**

- **вид с настоящими шрифтами.** Google Fonts из моего окружения
  недоступен (`ERR_CONNECTION_RESET`), тесты шли на системном шрифте.
  Он шире Oswald, то есть запас по ширине только увеличится, но
  посмотрите первый экран после публикации своими глазами;
- срабатывание настоящих пикселей — нужны подключённые счётчики;
- доставку сообщений в WhatsApp с реального телефона.
